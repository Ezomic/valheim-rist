# Rist: the three movement capstones, and none of them touches running.
#
# Tireless, Long wind and Long stride all used to finish on m_runStaminaDrainModifier, which is
# what let a hand of three cards push one stat six times and reach the clamp. They name
# something else now, and this is the regression guard for that as much as it is a test of the
# three new capstones: every assertion below reads "running x0.75" alongside the thing it is
# actually checking, and 0.75 is Tireless's five ranks and nothing else. A capstone creeping
# back onto running shows up here whichever card it was added to.
#
# The boundary matters more than the value, the same way it does for Steady footing: a capstone
# paid before it is earned passes any test that only ever looks at rank 5. So each one is read
# at rank 4 first.
#
# WHY THE DELAY IS NEVER READ AT ZERO. Sinews floors it at 0.25s, and that is load-bearing
# rather than tidy: stamina regen runs only once m_staminaRegenTimer has elapsed, and every
# point spent puts the timer back to m_staminaRegenDelay, so any value above zero cannot elapse
# while you are running. At exactly zero it can, regen out-paces the drain, and free sprinting
# comes back through a door with no clamp behind it. 1.00 less 0.60 is 0.40, which is above the
# floor and is what this asserts.
#
# SINGLEPLAYER. Ranks live on the server and `rist rank` refuses on a client.
#
# It leaves all three stones at rank 0.

clear
god

mod rist rank tireless 0
mod rist rank longwind 0
mod rist rank longstride 0
status remove GP_Eikthyr
wait 1

mod rist show
printed running x1.00 yes

mod rist show
printed delay 0.00s off yes

mod rist show
printed jump x1.00 yes

# ---- Tireless: the pause before stamina comes back.

mod rist rank tireless 4
wait 1

# Four ranks buy the stamina discount and not the capstone. Running is already cheaper here,
# which is the per-rank effect and is meant to be.
mod rist show
printed delay 0.00s off yes

mod rist rank tireless 5
wait 1
mod rist show
printed delay 0.60s off yes

# And the fifth rank did not quietly also deepen the running discount.
mod rist show
printed running x0.75 yes

# ---- Long stride: jump height.

mod rist rank longstride 4
wait 1
mod rist show
printed jump x1.00 yes

mod rist rank longstride 5
wait 1
mod rist show
printed jump x1.20 yes

# Long stride's capstone used to be -0.06 running. If it still were, this would read x0.69.
mod rist show
printed running x0.75 yes

# ---- Long wind: more of its own regen, and nothing on running.

mod rist rank longwind 5
wait 1

# Its capstone used to be -0.05 running. All three stones are at rank 5 here, which is the
# exact hand that reached the clamp, and running must still be Tireless's ranks alone.
mod rist show
printed running x0.75 yes

# The other two are unchanged by it, so the three capstones are not writing over each other.
mod rist show
printed delay 0.60s off yes

mod rist show
printed jump x1.20 yes

mod rist rank tireless 0
mod rist rank longwind 0
mod rist rank longstride 0
wait 1

# Back to bare, which proves the two written straight onto the player are restored and not
# merely stopped - a capstone that only ever added would leave the jump at x1.20 here.
mod rist show
printed jump x1.00 yes

mod rist show
printed delay 0.00s off yes
