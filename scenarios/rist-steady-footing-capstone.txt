# Rist: Steady footing pays no armour at any rank, and its capstone arrives at the fifth rank and not before.
#
# Written in 1.6.0 to prove an armour capstone. LHM-44 replaced that with Footing back (three seconds
# without a stagger after you recover from one), so what this reads now is the regression guard that
# no armour is paid at any rank, and the boundary: the capstone is the fifth rank's and not the
# fourth's. A capstone paid before it is earned passes any test that only ever looks at rank 5.
#
# Thick-hided's percentage is covered by rist-armour-scales. The last pair here is both stones
# at once: Thick-hided's 15% from its ranks and nothing from this one, because the two used to
# name the same field and "they add up" is exactly what stops being true if one of them ever
# writes the field instead of contributing to it.
#
# SINGLEPLAYER, same as the other one: ranks live on the server.
#
# It leaves both stones at rank 0.

clear
god

give ArmorIronChest:1
give ArmorIronLegs:1
tool ArmorIronChest
tool ArmorIronLegs
wait 1

mod rist rank thickhide 0
mod rist rank steadyfoot 0
wait 1
mod rist show
printed game x1.00 yes

# ---- the boundary.

mod rist rank steadyfoot 4
wait 1

# Four ranks of stagger and no armour, and no capstone yet.
mod rist show
printed game x1.00 yes

mod rist show
printed footing back: not carved yes

mod rist rank steadyfoot 5
wait 1

# The fifth rank no longer pays armour: x1.05 here would be the old capstone back.
mod rist show
printed game x1.00 yes

mod rist show
printed footing back: carved yes

# ---- both stones: Thick-hided's 15% from its ranks and nothing from this one.

mod rist rank thickhide 5
wait 1
mod rist show
printed game x1.15 yes

mod rist rank thickhide 0
mod rist rank steadyfoot 0
wait 1
mod rist show
printed game x1.00 yes
