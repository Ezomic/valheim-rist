# Rist: Quiet wake's capstone, Sleepers sleep on. A sleeping creature is not woken by you walking
# close, only by noise.
#
# The same flag word as Lose them: `rist show` prints what a client would read off this character,
#
#   carried: lose them yes|no, sleepers sleep on yes|no, rides the waves yes|no
#
# The wake itself needs a sleeping creature, which is prefab data this scenario does not assume. In
# play: find a sleeper (a creature lying down, in a crypt or a camp), walk up to well inside five
# metres without running or fighting. With the capstone it stays down; without it, it wakes as
# you come within range. A friend close enough without the stone wakes it as usual.
#
# THE BOUNDARY MATTERS MOST: rank four must publish nothing.
#
# SINGLEPLAYER. Ranks live on the server and `rist rank` refuses on a client.
#
# It leaves Quiet wake at rank 0.

clear
god

mod rist rank quietwake 0
wait 1
mod rist show
printed carried: lose them no, sleepers sleep on no yes

mod rist rank quietwake 4
wait 2
mod rist show
printed sleepers sleep on no yes

mod rist rank quietwake 5
wait 2
mod rist show
printed sleepers sleep on yes yes

mod rist show
printed sleepers sleep on: carved yes

mod rist rank quietwake 0
wait 2
mod rist show
printed sleepers sleep on no yes
