# Rist card catalogue.
#
# One card per line:
#
#   id | Name | flavour text | effect | value-per-rank | bonus effect | bonus value | sigil
#
# "effect" is either the literal name of a public float field on the game's SE_Stats
# class, or one of the specials below. Using the field name directly means any of the
# ~45 modifiers the game already has can be turned into a card by adding a line here -
# no code change, no rebuild.
#
# Specials:
#   *inventoryrow           adds rows to the player inventory grid - UNUSED, see below
#   *stamina:move           run, jump, dodge, swim and sneak all cost less
#   *stamina:fight          attacking and blocking both cost less
#   *attackspeed:melee      swings faster with a weapon
#   *attackspeed:tools      swings faster with a pickaxe, hammer, hoe or cultivator
#   *attackspeed:ranged     draws faster with a bow or crossbow
#   *exploreradius          the map uncovers further as you walk
#   *windcone               sail closer to the wind before the sail dies
#   *rowspeed               rows faster, forward and back
#
# Rank 5 is meant to be the moment, so a capstone should be an unlock rather than a larger
# number wherever the game gives us one: a row of inventory, immunity to falling, levels in
# every skill. Four of them do that. Nothing anywhere carries a drawback, on purpose - a
# choice you regret is a choice that stops you playing.
#
# NO CARD GRANTS AN INVENTORY ROW ANY MORE, and *inventoryrow is left in the code rather
# than removed so an older catalogue still loads. Rist gave rows because vanilla gave none;
# Valheim 1.0 sells them from the trader, so the mod was answering a question the game has
# since answered itself. Two capstones used to hand one out on top of everything a player
# could buy, and the result was an inventory nobody had to think about.
#
# The older argument still holds and is kept here because it is the reason not to bring the
# row back as a card of its own: as its own card it was the strongest pick in the catalogue
# and taken first every time, which is not a choice.
#
# MOVE SPEED IS CAPPED AT 10% AND COMES FROM ONE CARD ONLY. Long stride is the only source;
# Tireless used to add 8% on top, and the two together reached 23%. Speed is the one stat a
# player carries out of this world: it is always on, never noticed while you have it, and its
# absence is what gets felt - a player told us Rist had made his other, unmodded playthroughs
# feel broken. Every other card here is felt in the moment it matters. Do not add a second
# source, and note that m_windMovementModifier multiplies speed too, so a wind card would sit
# on top of this cap rather than inside it.
#
# Value is per rank and accumulates: rank 3 of a 15-per-rank card gives 45.
# Cards stop being offered once they reach MaxRank in the config.
#
# The last field is the SIGIL: the rune cut into the middle of this rist's stone in the
# rists panel. Optional; a card without one falls back to the first letter of its id.
#
# Written as a Latin letter, not as a runic Unicode character. The game font called "rune"
# is a Latin-mapped decorative face - type F, get the rune - and runic code points come out
# of it as empty boxes. Confirmed the hard way, on a screen of twenty-five tofu squares.
#
# The two fields before it are the CAPSTONE and are optional. A card that names one grants it
# once per BonusEvery ranks - at the default MaxRank 5 and BonusEvery 5, that is once, on
# the final upgrade. A capstone can name anything an effect can, including a special.
#
# Sign conventions differ between fields and are the game's, not ours. The stamina-use
# modifiers are fractions where negative means cheaper, so -0.05 is a 5% discount per
# rank. Read a value out loud before adding it.
#
# Four fields count from 1 rather than 0 and the code adds that 1 for you - the three
# regen multipliers and m_damageModifier. Write the plain fraction here.

# Two cards that widen what the world gives back rather than what you do to it, and neither
# can follow you out of this world the way move speed did. Far sight is felt only on ground
# you have not walked; Weatherly only at sea.
#
# Far sight multiplies Minimap.m_exploreRadius, which is 100 in vanilla - so rank 5 is 125.
#
# Weatherly is the sailing model, which is seven lines in Ship.GetWindAngleFactor: sailing
# across the wind gives 1.0, dead up or downwind gives 0.7, and a hard cone from dot 0.75 to
# 0.8 takes it to nothing. That cone is the only reason tacking exists. The card narrows it,
# scaling both edges 6% a rank closer to dead upwind, and bends the sail's push toward the bow
# by the same amount inside the arc it opens. The bend is not decoration: vanilla aims the force
# along windDir + forward, which goes sideways near the wind, so narrowing alone unlocked
# headings that were all slower to windward than vanilla's own best, and nobody could feel it.
# At rank 5 the best windward heading moves from 52 degrees off the wind to about 36, roughly
# 71% faster upwind. Dead upwind stays fully dead at every rank, so tacking survives.
#
# The capstone rows faster, not sails faster. Rowing is a separate force from the sail
# (m_backwardForce, used only at Slow and Back), and it is what you are left doing when you
# still cannot point high enough. It used to be a tacking bonus on the sail, which only made
# the card's own job more so; rowing answers the same annoyance from the other end.
farsight    | Far sight      | The land gives up its shape.      | *exploreradius           | 0.05  | *exploreradius            | 0.10 | F
weatherly   | Weatherly      | She points nearer the wind.       | *windcone                | 0.06  | *rowspeed                 | 0.20 | W
